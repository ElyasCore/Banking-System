## Banking System

A simple Java console banking system that allows the user to manage a main account balance and perform basic banking operations.

The project focuses on practicing methods, parameters, return values, input validation, and managing program state through a menu-driven application.

### Features

* Check account balance
* Deposit money
* Withdraw money
* Transfer money to another account
* Validate transaction amounts
* Prevent withdrawals and transfers above the available balance
* Update account balances after transactions
* Handle invalid menu choices

### Concepts Practiced

`Methods` · `Parameters` · `Return Values` · `Scanner` · `while` · `switch` · `if/else` · `Variables` · `Logical Operators` · `Input Validation` · `State Management` · `break`

Built as part of my Java learning journey to strengthen my understanding of methods and practice building a more structured menu-driven application.
